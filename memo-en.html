道場 · Cheatsheet

The Dojo's commands, chapter by chapter

The cheat sheet to keep on hand. 20 chapters (one bonus included) · the essential commands with a short explanation.
⬇️ PDF ← The Dojo
Notation: <f> = a file · <name> = replace this · [..] = optional · | = “or”. Many system commands require sudo (admin rights).
CH 1The Foundations⬜
pwdshows the current folder (“where am I?”)
whoamithe current user's name
idfull identity: uid, gid, groups
lslists the contents of a folder
ls -lalists everything, hidden files + details
man <cmd>a command's manual (q to quit)
<cmd> --helpa command's quick help
CH 2Navigation⬜
cd <folder>enter a folder
cd ..go up one level
cd ~back to the home folder (ou cd seul)
cd /go to the root
treeshows the tree
absolute vs relative/home/user (everywhere) vs Documents (from here)
CH 3Files & folders🟩
cat <f>shows the contents of a file
mkdir <name>create a folder (-p creates the parents)
touch <f>create an empty file
cp source destcopy a file
mv old newmove OR rename
rm <f>delete (permanent!) · rm -r for a folder
wildcards * ?rm *.log acts on several files
find <where> -namefind files by name, recursively
CH 4Users & permissions🟥
ls -lreads the permissions (e.g. -rwxr-xr--)
chmod +x <f>make a file executable
chmod 755 <f>permissions in numbers (r=4, w=2, x=1)
chown user:grp <f>change the owner (sudo)
sudo <cmd>run as administrator
CH 5Editors (nano / vim)🟩
nano <f>simple editor (Ctrl+O save, Ctrl+X quit)
vim <f>modal editor (i insert, Esc, :wq save+quit)
echo "txt" > fwrite into a file (overwrites)
echo "txt" >> fappend to the end (without overwriting)
CH 6Search & filtering🟥
head / tail -n <f>the start / end of a file
tail -f <f>follow a log live
grep <pattern> <f>search for text (-i -n -c -v -r)
cmd1 | cmd2the “pipe”: chains commands
wc -lcount the lines
cmd > f · >> fredirect the output to a file
CH 7System processes🟥
ps · ps auxlist the processes
topreal-time activity (q to quit)
kill <PID>stop a process (kill -9 forces)
CH 8User management🟥
cat /etc/passwdthe list of accounts
sudo useradd -m <name>create a user
sudo passwd <name>set its password
groupsa user's groups
sudo groupadd <name>create a group
sudo usermod -aG grp useradd a user to a group
sudo userdel -r <name>delete a user
CH 9Services & systemd🟧
systemctl status <svc>the state of a service
sudo systemctl start/stopstart / stop a service
sudo systemctl enablelaunch it at boot
files .servicein /etc/systemd/system/ (ExecStart, After)
CH 10Deploy a site (nginx)🟧
systemctl status nginxcheck that nginx is running
/etc/nginx/the web server config
/var/www/html/the site files
tail -f …/access.logfollow the visits live
curl http://localhosttest the site from the command line
CH 11Network & SSH🟧
ip aIP address / network config
ping <host>test whether a machine responds
cat /etc/resolv.confthe DNS servers
ssh-keygengenerate an SSH key (~/.ssh/)
ssh user@ipconnect to a remote machine
CH 12Security & hardening🟧
sudo ufw statusthe firewall state
sudo ufw enableenable the firewall · ufw allow <port>
grep Failed …/auth.logspot failed SSH attempts
/etc/ssh/sshd_configharden the SSH connection
sudo visudowho is allowed to use sudo
CH 13System & disk🟧
df -hthe available disk space
du -sh <folder>the size of a folder
lscputhe processor info
free -hthe memory (look at available)
uname -athe system version
CH 14System monitoring🟧
uptimeuptime + system load
w · whowho is logged in
lastthe login history
htopun top en couleur, plus lisible
vmstatCPU / memory / disk at a glance
CH 15Scheduling (cron)🟧
crontab -llist your scheduled tasks
crontab -eedit: min h day month dow cmd
datethe system date and time
CH 16Bash scripting🟥
#!/bin/bashthe “shebang”: 1st line of a script
VAR=x · $VARvariables (e.g. echo $PATH)
./script.shrun the script (after chmod +x)
echo $?the return code (0 = all good)
$(commande)substitution: inserts a command's result
CH 17Git — version control⬛
git initcreate a repository in the folder
git statusthe state of the files (your compass)
git add <f>add to the index (git add . = everything)
git commit -m "msg"record a snapshot
git logre-read the commit history
CH 18Virtualization (KVM)⬛
egrep -c 'vmx|svm' /proc/cpuinfoCPU virtualization-capable? (> 0 = yes)
sudo apt install qemu-kvminstall the hypervisor
sudo systemctl enable --now libvirtdstart the virtualization daemon
virsh list --alllist the virtual machines
virsh start <vm>start a VM
CH 19Archives & compression⬛
tar czf a.tar.gz <folder>create a compressed archive
tar xzf a.tar.gzextract an archive
the lettersc=create, x=extract, z=gzip, f=file
